# AI Quest: AI From Zero

A browser game that teaches AI from scratch through simulations: tokens, LLMs, parameters, context windows, memory, prompting, local vs cloud models, subscriptions vs APIs, API keys, embeddings and RAG, and agents.

Each level has hands-on lessons in lookalike tools (chat apps, an Ollama terminal, an API console), missions, an incident desk and a boss fight.

**Play:** open `index.html` in a browser, or visit the GitHub Pages site for this repo.

## Editing

Edit `ai-from-zero.html`, then run `sh build.sh` to regenerate `index.html`.
